# Level 2 - Task 2: Responsive Web Design & Hamburger Menu

This repository contains the solution for **Level 2 - Task 2** of the Web Development Internship.

## Project Features

- **Responsive Web Design**: Converts a basic webpage into an adaptive layout that fluidly adjusts across desktop, tablet, and mobile screen sizes using CSS media queries.
- **Mobile-Friendly Navigation**: Desktop inline navigation menu that collapses into an animated 3-bar hamburger icon on smaller screens (= 768px).
- **Interactive Mobile Drawer**: Smooth slide-down navigation drawer with touch-friendly links, outside click dismissal, and escape key navigation.
- **Responsive Components**: Includes Hero section, Metrics/Stats row, 6-card Services grid, Portfolio gallery, 3-tier Pricing cards, and a Contact form.

## Files

- index.html - Page structure, content sections, and accessible hamburger navigation
- style.css - Custom styling, flexbox/grid layouts, and responsive CSS media queries
- script.js - JavaScript handling hamburger toggle, link clicks, and outside click dismissals
